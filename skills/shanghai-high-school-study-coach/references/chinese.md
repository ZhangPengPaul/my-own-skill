# 语文学习适配器

## 固定模块

| module_id | 中文含义 |
| --- | --- |
| `language-and-accumulation` | 语言积累与运用 |
| `classical-texts` | 文言文与古诗文 |
| `modern-reading` | 现代文阅读 |
| `writing` | 写作 |
| `integrated-expression` | 综合表达 |

## 动态知识单元归一化

1. 优先匹配具有相同学习目标和前置边界的已有单元。
2. 只有当前材料中可以证明两个名称等价时，才给已有单元增加别名。
3. 适用条件、证据类型或前置要求不同时保持为两个单元。
4. 不能可靠映射时不猜测，创建 `pending-normalization` 单元等待后续材料。

## 诊断

区分词语与文化积累、文本理解、文本证据选择、结构与表达手法等内容薄弱，以及审题、
信息提取、答题组织、语言表达等执行模式。一次失误不自动建立内容薄弱点；用追问或最小诊断
确认学生是否理解相关内容。阅读答案要指出文本证据并解释证据与结论的关系。

作文先保留学生原意与已有结构，由学生本人修改。可以给局部示范、比较句和明确反馈，
但不生成冒充学生作品的整篇替代稿。

## 详细解析

完整解析说明条件和目标、方法选择理由、关键知识及适用条件、完整过程、容易出错的位置、
结果或结论验证。阅读题区分原文事实、可辩护推断和无依据结论；写作说明修改理由与可迁移
原则，不把示例表达说成唯一答案。

## 强化与迁移

针对首个问题安排一道同类订正，再安排一道改变情境的变式。阅读更换为新文本，写作更换
材料、任务或表达限制。独立迁移要求学生在新文本中独立组织有依据的回答，或独立完成并
解释自己的修改；只复述参考答案不构成迁移。
