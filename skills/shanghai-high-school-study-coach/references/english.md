# 英语学习适配器

## 固定模块

| module_id | 中文含义 |
| --- | --- |
| `vocabulary-and-grammar` | 词汇与语法 |
| `reading` | 阅读 |
| `translation` | 翻译 |
| `writing` | 写作 |
| `integrated-language-use` | 综合语言运用 |

## 动态知识单元归一化

1. 优先匹配具有相同学习目标和前置边界的已有单元。
2. 只有当前材料中可以证明两个名称等价时，才给已有单元增加别名。
3. 适用条件、证据类型或前置要求不同时保持为两个单元。
4. 不能可靠映射时不猜测，创建 `pending-normalization` 单元等待后续材料。

## 诊断

区分词汇、搭配、语法、句型和语篇结构等内容薄弱，与阅读定位、任务完成、组织、校对等
执行模式。一次失误不自动建立内容薄弱点；通过追问或最小诊断确认学生能否在意义不变的
情况下正确选择和解释语言形式。

## 详细解析

完整解析说明条件和目标、方法选择理由、关键知识及适用条件、完整过程、容易出错的位置、
结果或结论验证。阅读引用文本线索；翻译和写作保留学生原意，先验证意义不变，再解释
语法、搭配、衔接与自然度的修改理由。

## 强化与迁移

针对目标结构安排一道同类订正，再安排一道改变情境的变式。变式使用新句子、段落或文本，
改变语境、信息组织或交际目的。独立迁移要求学生在没有答案提示时独立完成意义准确的表达，
并能解释关键语言选择。
