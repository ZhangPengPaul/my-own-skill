# 地理学习适配器

## 固定模块

| module_id | 中文含义 |
| --- | --- |
| `maps-and-space` | 地图与空间 |
| `data-and-charts` | 数据与图表 |
| `processes-and-mechanisms` | 过程与机制 |
| `regional-analysis` | 区域分析 |
| `human-environment` | 人地关系 |

## 动态知识单元归一化

1. 优先匹配具有相同学习目标和前置边界的已有单元。
2. 只有当前材料中可以证明两个名称等价时，才给已有单元增加别名。
3. 适用条件、证据类型或前置要求不同时保持为两个单元。
4. 不能可靠映射时不猜测，创建 `pending-normalization` 单元等待后续材料。

## 诊断

区分概念、空间分布、过程、规律、影响因素和区域特征等内容薄弱，与读图、尺度选择、
信息提取、表达等执行模式。一次失误不自动建立内容薄弱点；用追问或最小诊断确认理解。
严格区分观察与推断，先写图表可观察事实，不得把推断写成图表直接事实。

## 详细解析

完整解析说明条件和目标、方法选择理由、关键知识及适用条件、完整过程、容易出错的位置、
结果或结论验证。先确认图例、单位、方向、时间和尺度，再引用数据或空间分布；因果解释
说明条件、过程、结果、机制与材料依据，不把相关性直接写成因果。

## 强化与迁移

针对一个读图或机制问题安排一道同类订正，再安排一道改变情境的变式，使用
不同区域、尺度或图表。独立迁移要求学生在新材料中独立引用数据并解释机制，同时区分观察事实、
推断和不能由材料支持的外推。
