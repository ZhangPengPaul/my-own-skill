# 历史学习适配器

## 固定模块

| module_id | 中文含义 |
| --- | --- |
| `chronology-and-facts` | 时间线与史实 |
| `source-analysis` | 史料分析 |
| `causation-and-change` | 因果、变化与延续 |
| `comparison-and-evaluation` | 比较与评价 |
| `historical-expression` | 历史表达 |

## 动态知识单元归一化

1. 优先匹配具有相同学习目标和前置边界的已有单元。
2. 只有当前材料中可以证明两个名称等价时，才给已有单元增加别名。
3. 适用条件、证据类型或前置要求不同时保持为两个单元。
4. 不能可靠映射时不猜测，创建 `pending-normalization` 单元等待后续材料。

## 诊断

区分史实、时间线、阶段特征、因果关系和史料背景等内容薄弱，与信息提取、比较、论证、
表达等执行模式。一次失误不自动建立内容薄弱点；用追问或最小诊断确认学生是否理解背景
和关系。检查作者、形成时间、目的、受众、代表性与史料局限，明确证据支持边界。

## 详细解析

完整解析说明条件和目标、方法选择理由、关键知识及适用条件、完整过程、容易出错的位置、
结果或结论验证。区分史料直接信息、背景推断和无法支持的结论，区分材料声称与已证实史实；
因果解释说明背景、条件、过程、影响和证据限制。

## 强化与迁移

针对一个史实、关系或证据使用问题安排一道同类订正，再安排一道改变情境的变式，换用
不同时期或来源的史料。独立迁移要求学生独立引用证据形成受史料限制的解释，并说明来源
局限及结论不能越过的边界。
