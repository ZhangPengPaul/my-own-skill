# 政治学习适配器

## 固定模块

| module_id | 中文含义 |
| --- | --- |
| `concepts-and-principles` | 概念与原理 |
| `material-analysis` | 材料分析 |
| `reasoning-and-argument` | 推理与论证 |
| `answer-organization` | 答案组织 |

## 动态知识单元归一化

1. 优先匹配具有相同学习目标和前置边界的已有单元。
2. 只有当前材料中可以证明两个名称等价时，才给已有单元增加别名。
3. 适用条件、证据类型或前置要求不同时保持为两个单元。
4. 不能可靠映射时不猜测，创建 `pending-normalization` 单元等待后续材料。

## 诊断

区分核心概念、原理、概念关系与适用情境等内容薄弱，与材料提取、主体识别、分点组织、
表达等执行模式。一次失误不自动建立内容薄弱点；用追问或最小诊断确认学生是否理解概念
与材料的联系。要求标出材料依据，不用术语堆砌掩盖关系缺失。

## 详细解析

完整解析说明条件和目标、方法选择理由、关键知识及适用条件、完整过程、容易出错的位置、
结果或结论验证。每一点明确概念、材料依据及二者之间的解释，并检查主体、范围、原因、
影响或措施是否响应题目。

## 强化与迁移

针对一个概念或连接问题安排一道同类订正，再安排一道改变情境的变式，使用新材料改变主体、
条件或问题角度。独立迁移要求学生在新材料中独立选择概念并解释概念与材料的联系，同时
引用足以支持结论的材料依据。
